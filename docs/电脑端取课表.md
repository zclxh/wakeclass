# 电脑端取课表（没有 VPN、只能校园网时）

适用：教务系统只在**校园网 / 内网**里能打开，学校又**没有 VPN**。
手机在外面连不上教务，但课表本身是本地数据 —— 在电脑上把课表「取」出来，
发到手机导入一次就行，之后课表、提醒、桌面小组件全部离线可用。

## 三条路，按省事程度排

| 方式 | 适合 | 耗时 |
|---|---|---|
| **截图导入** | 任何系统，什么都不用装 | 1 分钟，识别后可校对 |
| **粘贴导入 + 书签脚本** | 想要最准（单双周、教室、教师都不出错） | 首次配 2 分钟，之后每学期 3 秒 |
| **教务直连** | 人正在校内、手机连着校园网 | 直接登录，最准 |

> 每学期只需要做一次。换学期再取一次即可。

## 一、最省事：截图

1. 电脑（连着校园网）打开教务课表页，截一张完整的图（含星期表头 + 左侧节次列）
2. 微信「文件传输助手」发到手机
3. App → 导入 → 截图导入 → 从相册选择 → 校对 → 导入

## 二、最准：书签脚本（推荐给正方用户）

> ⚠️ **正方（`jwglxt`）的课表格子是浏览器里用 JS 画出来的**，
> 右键「查看网页源代码」拿到的只是空壳，里面没有课程。
> 所以正方必须用脚本或者 F12 的接口返回，复制源代码是白费劲。

### 1. 加一个书签

1. 电脑用 Chrome / Edge 打开任何页面，按 `Ctrl + D` 收藏
2. 名字随便填（比如 `取课表`）
3. 网址**清空**，粘贴下面**整段**（一行，别换行）
4. 保存

**正方（jwglxt）专用**：直接调课表接口，拿回 `kbList` JSON，单双周最准。

```text
javascript:(async()=>{const cp=t=>new Promise((ok,no)=>{try{if(navigator.clipboard&&window.isSecureContext){navigator.clipboard.writeText(t).then(ok,no);return}const a=document.createElement("textarea");a.value=t;a.style.position="fixed";a.style.opacity="0";document.body.appendChild(a);a.select();const r=document.execCommand("copy");a.remove();r?ok():no(new Error("浏览器拒绝复制"))}catch(e){no(e)}});try{const base=location.pathname.split("/kbcx/")[0];const q=new URLSearchParams();q.set("xnm",(document.querySelector("#xnm")||{}).value||"");q.set("xqm",(document.querySelector("#xqm")||{}).value||"");q.set("kzlx","ck");const r=await fetch(base+"/kbcx/xskbcx_cxXsKb.html?gnmkdm=N2151",{method:"POST",headers:{"Content-Type":"application/x-www-form-urlencoded;charset=UTF-8"},body:q.toString()});const t=await r.text();if(!t||t.length<20)throw new Error("接口没有返回内容");await cp(t);alert("已复制 "+t.length+" 个字符。\n发到手机后用「粘贴导入」")}catch(e){alert("取数据失败："+e+"\n备选：F12 → Network → xskbcx_cxXsKb.html → 右键 Copy response")}})()
```

**任意系统通用**：把页面上已经渲染好的课表表格 HTML 复制出来。

```text
javascript:(()=>{const ts=[...document.querySelectorAll("table")];let best=null,score=0;for(const t of ts){const n=(t.textContent.match(/星期[一二三四五六日天]/g)||[]).length;if(n>score){score=n;best=t}}if(!best){alert("没找到课表表格：请先打开课表页面（能看到课程格子）");return}const h=best.outerHTML;const a=document.createElement("textarea");a.value=h;a.style.position="fixed";a.style.opacity="0";document.body.appendChild(a);a.select();const ok=document.execCommand("copy");a.remove();alert(ok?("已复制表格 "+h.length+" 个字符，发到手机后粘贴导入"):"复制失败：请改用 F12 复制")})()
```

### 2. 用

1. 电脑打开教务课表页（能看到一行行课程格子）
2. 点一下这个书签 → 弹窗「已复制 N 个字符」
3. 微信「文件传输助手」把内容发到手机 → 复制
4. App → 导入 → 粘贴导入 → 从剪贴板粘贴 → 解析 → 校对 → 导入

### 不想加书签？用 F12

1. 课表页按 `F12` → `Network`（网络）
2. 刷新页面（正方：切换学期也会触发）
3. 找到 `xskbcx_cxXsKb.html` → 点开 → 右键 `Copy response`
4. 剩下同上

强智（`jsxsd`）/ 青果 / URP 这类**服务器直接渲染**的系统不用这么麻烦：
右键「查看网页源代码」→ `Ctrl+A` → `Ctrl+C` 就带着表格。

## 三、文件方式（内容太大时）

几百 KB 的网页源码塞进聊天框很痛苦，可以走文件：

1. 电脑上把取到的内容存成 `.html` / `.txt` / `.json`
2. 微信发文件到手机
3. 手机微信里点开文件 → 「用其他应用打开」→ 选**醒课**（会自动解析）
4. 或者：App → 粘贴导入 → 「选择文件」

App 会自动识别 UTF-8 / GBK 编码。

## 常见问题

**Q：为什么编辑器里粘进去是空的？**
A：内容超过 2 万字符时 App 只在内存里处理，不往输入框塞（否则会卡），
页面上会显示「已读取 N 个字符」，直接点「解析」即可。

**Q：脚本点了没反应？**
A：确认打开的是**课表页**（能看到课程格子），不是登录页。
正方脚本还要求当前浏览器**已经登录**教务（同源请求会带 Cookie）。

**Q：导入后还要联网吗？**
A：不需要。「教务直连」才需要网络，课表、提醒、小组件都是本地数据。
